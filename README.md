# 🔬 과학축제 바이브 코딩 프롬프트 자동 생성기 (24종 템플릿 지원)

과학 축제 참가자(초·중학생 및 학부모)들이 '바이브 코딩(자연어로 코딩하기)'을 쉽고 재미있게 체험할 수 있도록 도와주는 웹앱 프롬프트 생성기입니다.

## ✨ 24가지 웹앱 템플릿 라인업

### 🎮 카테고리 1: 아케이드 & 퍼즐 게임 (8종)
1. **스네이크 게임** 🐍 - 뱀이 밥을 먹으며 길어지는 클래식 아케이드
2. **장애물 피하기 게임** 🏃‍♂️ - 다가오는 장애물을 점프해서 피하는 액션 러너
3. **카드 뒤집기 메모리 게임** ❓ - 두 장의 카드를 뒤집어 짝을 맞추는 기억력 게임 (물음표 카드)
4. **가위바위보 게임 만들기** ✌️ - 나만의 캐릭터와 상성 룰(불🔥/물💧/풀🌿) 대결
5. **하늘에서 떨어지는 장애물 피하기** ☄️ - 하늘에서 쏟아지는 장애물을 좌우로 회피
6. **핀볼형 랜덤 뽑기 / 룰렛** 🎡 - 회전판과 핀볼 물리 효과로 즐기는 경품 추첨
7. **방탈출 비밀번호 추리 게임** 🔐 - 밀실 속 힌트 오브젝트를 조사해 도어락 암호 해독
8. **무한 클릭커 (노가다) 게임** 🍪 - 클릭할 때마다 진화하고 자동 로봇을 구매하는 방치형 탭 게임

### 🧠 카테고리 2: 퀴즈 & 두뇌 훈련 (6종)
9. **어림값 계산기 만들기** ⚖️ - 물건 가격, 거리, 무게를 직관적으로 예측하는 수학 직관 훈련
10. **영어 단어 퀴즈 게임** 🔤 - 그림과 힌트를 보고 스피드로 맞히는 단어 퀴즈
11. **내가 만드는 넌센스 OX 퀴즈** ⭕ - 올빼미 MC와 함께하는 상식 & 넌센스 OX 배틀
12. **쌓기나무 입체도형 추측 게임** 🧱 - 위/앞/옆 3면 투영도를 보고 블록 개수 맞히기
13. **도덕적 딜레마 저울 앱** ⚖️ - 정직 vs 우정 등 두 가치 사이에서 선택하고 AI 피드백 수신
14. **순발력 테스트 (떨어지는 물건 잡기)** ⚡ - 신호가 오자마자 클릭! 밀리초(ms) 단위 반응속도 측정

### 🌌 카테고리 3: 시뮬레이터 & 상호작용 (9종)
15. **태양계 공전 시뮬레이션** 🪐 - 태양을 중심으로 행성들이 도는 교육용 시뮬레이션
16. **계절별 별자리 관측 시뮬레이터** 🌌 - 사계절 밤하늘을 돌려보며 별자리 선을 잇고 신화 탐구
17. **상호작용 이북 (e-Book) 만들기** 📖 - 단어를 누르면 소리가 나고 그림이 튀어나오는 인터랙티브 동화
18. **MBTI 심리/유형 검사 앱** 🧩 - 4가지 질문으로 나의 동물/직업 캐릭터를 찾는 심리테스트
19. **나를 소개하는 인터랙티브 웹페이지** 👤 - 해커 터미널/다이어리 테마와 마우스 파티클 자기소개
20. **감정 날씨 일기장** 🌦️ - 기분을 날씨로 표현하면 배경에 비나 햇살이 내리는 힐링 다이어리
21. **소시오그램 (인간관계) 시각화 보드** 🕸️ - 나와 친구들을 젤리 물리 엔진으로 연결하는 관계망
22. **웹 기반 디지털 런치패드 (악기 연주)** 🎹 - 패드를 터치하면 신디사이저 비트와 네온 조명이 연주
23. **타이머 & 집중력 뽀모도로 시계** ⏳ - 시간이 흐를수록 씨앗이 자라 꽃이 피어나는 집중 시계

### ✨ 카테고리 4: 자유 창작 (1종)
24. **자유 창작 웹앱 (간이 PRD)** 🪄 - 머릿속 상상을 웹앱 이름, 기능, UI 레이아웃, 마스코트로 기획

## 🚀 배포 및 오프라인 단일 파일 사용 안내
1. **GitHub ➜ Vercel 배포**: 본 저장소를 GitHub에 푸시 후 Vercel에서 `Import`하면 Vite 세팅(`vercel.json`)으로 원클릭 무료 배포됩니다.
2. **단일 HTML 파일 다운로드**: 사이트 우측 상단의 **[HTML 저장]** 버튼을 누르면 다운로드된 HTML 파일 하나만으로 인터넷 브라우저 어디서든 바로 단독 실행 가능합니다.
